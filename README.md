# Weather App

Full-stack weather app with auth, city search, and real-time broadcast messages.

## Setup

1. `npm run install:all`
2. Copy `server/.env.example` to `server/.env` and fill in your OpenWeatherMap API key
3. `npm run dev`

## Run

```bash
npm run dev        # starts both client (:5173) and server (:3001)
npm test           # runs all tests
```
